# 🌌 Rintia Islam - Full-Stack Developer Portfolio

Welcome to the repository for my personal portfolio website. This is a modern, fully responsive, and highly interactive web application designed to showcase my academic background, technical skills, core projects, and hobbies.

🖥️ **Live Link:** [personal-portfolio-eight-omega-11.vercel.app](https://personal-portfolio-eight-omega-11.vercel.app)

---

## 🚀 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS (Modern Glassmorphism, glow cards, and custom transitions)
- **Iconography:** Lucide Icons (Lucide-React)
- **Deployment:** Vercel

---

## ✨ Key Features & Sections

### 1. ⚡ Modern Centered Hero
- Center-aligned typography displaying key headings, active role status badge ("Open to Work"), and responsive CTA buttons.
- Features quick social links (GitHub, LinkedIn, Twitter, and Email) represented by sleek, custom SVG vector icons.

### 2. 📖 About Me & "Beyond the Code"
- Narrative introduction highlighting coding motivations, workflow details, and team alignment.
- A **Beyond the Code** interest matrix presenting hobby cards (Travel, Cooking & Baking, Photography, Painting) with dynamic Lucide-React icon renders (`Map`, `ChefHat`, `Camera`, `Palette`).

### 3. 🛠️ Skills Dashboard
- Segmented technical charts categorized under Frontend, Backend, and Development Tools, complete with percentage progress overlays.

### 4. 🎓 Academic Timeline (Education Only)
- Replaced work experience layouts with a single-column, centered timeline highlighting formal education history.
- Highlights:
  - **B.Sc. in Electrical and Electronics Engineering (Majored in CS)** – *University of Dhaka* (2017 - 2022)
  - **HSC** – *Birshreshtha Munshi Abdur Rouf Public College* (2016)

### 5. 💼 Featured Projects Showcase
Showcases three production-ready web applications, integrated with dynamic detail routing (`/projects/[id]`):
1. **Soft Skills Mastery:** Next.js 16 app powered by Gemini AI, featuring Better Auth, MongoDB Atlas, and TanStack query caching.
2. **WisdomIO:** MERN stack storytelling platform featuring premium post unlocks, Stripe checkout portal, and dashboard analytics.
3. **Pawfect Match:** Full-stack pet adoption listing platform designed with Express.js, MongoDB, and DaisyUI.

### 6. 📬 Gmail-Integrated Contact Section
- Designed a contact form that dynamically structures mail variables on submit.
- Automatically launches a pre-filled browser Gmail web composition tab (`mail.google.com/mail/?view=cm`) displaying only the message body for frictionless communication.

## 🛠️ Local Development Setup

To run this project locally, execute the following commands in your shell:

### 1. Clone the repository
```bash
git clone https://github.com/rintia/portfolio-rintia.git
cd portfolio-rintia
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the Turbopack development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or port `3001` if port 3000 is occupied) in your browser to view the application.

### 4. Build for production
```bash
npm run build
```
